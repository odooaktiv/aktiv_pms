qAktiv Odoo Days Contest
=======================
Aktiv Odoo Days Contest (ak_odoo_days_contest)

Configuration
=============
* As an ERP Manager (or any user in the **Odoo Days Contest** group):

1. Open **Aktiv Odoo Days > Odoo Days Objective** and create the
   objectives that should appear as checkboxes.
2. Open **Aktiv Odoo Days > Participant Type** and create each type,
   linking it to the survey that participants of that type should take.
3. Visit `/odoo/days/contest` to verify the landing page.
