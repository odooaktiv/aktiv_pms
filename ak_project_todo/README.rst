Aktiv Project To-do
=======================
Aktiv Project To-do (ak_project_todo)

Configuration
=============
* Navigate to **To-do** to manage SOPs, User Manuals, and Documents in one place.
* Use **To-do > Configuration** to set up project task security and categories.
* Assign SOP documents to users via the **SOP Assignment** wizard.
* Use the **Invite** wizard to add collaborators to a document or task.
