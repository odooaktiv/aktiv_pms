Aktiv Public Holidays
=======================
Aktiv Public Holidays (ak_public_holidays)

Configuration
=============
* Navigate to **Employees > Configuration > Public Holidays** to define the list of public holidays.
* Public holidays are visible on employee records and public employee profiles.
* Use **Employees > Configuration** to link holidays to specific employees or globally.
