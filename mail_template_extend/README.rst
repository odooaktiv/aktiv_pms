Email Template Layout Changes
=======================
Email Template Layout Changes (mail_template_extend)

Configuration
=============
* This module automatically removes the footer from the default Odoo email template layout.
* No manual configuration is required after installation.
* The changes apply globally to all outgoing emails that use the standard Odoo email layout.

Odoo modules dependencies
=========================
