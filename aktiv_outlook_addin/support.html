Aktiv for Outlook — Support

This add-in shows information from your Odoo database alongside the email you are reading.

Requirements

Odoo 19
Reachable over HTTPS with a valid public certificate.
The Mail Plugin module
Enable it in Odoo under Settings → General Settings → Integrations → Mail Plugin.
An internal Odoo user account
Portal users cannot connect this add-in. Odoo restricts inbox linking to internal users, and there is no way around it.

Common problems

"The Mail Plugin module isn't installed on that Odoo database"
Enable Mail Plugin in Odoo's General Settings, then reconnect.
"Only Internal Users can link their inboxes to this database"
You signed in as a portal user. Sign in with an internal account.
"Your Odoo access has expired or was revoked"
The API key was removed in Odoo. Reconnect from the panel to issue a new one. You can review keys under Settings → Users → your user → API Keys.
The panel is blank
Usually your Odoo server is not sending CORS headers — most often a reverse proxy in front of Odoo stripping them.
