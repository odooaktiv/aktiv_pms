Aktiv Survey
=======================
Aktiv Survey (ak_survey)

Configuration
=============
* This module extends the **Aktiv Odoo Days Contest** survey functionality.
* Navigate to **Surveys** to manage survey results and generate contest certificates.
* Use the **Survey Winner** wizard to select and announce winners.
* Contest certificates can be printed using the built-in report template.

Odoo modules dependencies
=========================
* ak_odoo_days_contest
