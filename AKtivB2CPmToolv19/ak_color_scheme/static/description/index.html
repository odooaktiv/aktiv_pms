Color Scheme

This module is used to apply color scheme in Odoo.

Explore this module

Overview Key Features Setup & Configuration Screenshots

Overview

With this module company or user can select color scheme to apply in Odoo.

Features

Allow companies to select color scheme in odoo for both light and dark mode.

Allow users to select color scheme in odoo for both light and dark mode if users allowed.

Allow companies to create and update color scheme in odoo for both light and dark mode or both.

Allow users to configure company specific color scheme.

Setup & Configuration

Prerequisites before Installation

  • No prerequisites are required before the installation

Configuration

Need to configure color schemes for light and dark from settings.
