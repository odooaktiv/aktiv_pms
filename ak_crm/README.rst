Aktiv CRM
=======================
Aktiv CRM (ak_crm)

Configuration
=============
* Go to **CRM** menu to manage leads, opportunities, stages, and types.
* Use **CRM > Configuration > Stages** to set up pipeline stages.
* Use **CRM > Configuration > CRM Types** to define lead/opportunity types.
* Use **CRM > Configuration > Technologies** and **Odoo Versions** for tagging.

Odoo modules dependencies
=========================
* crm,
* mail
