Aktiv Customer Portal
=======================
Aktiv Customer Portal (ak_customer_portal)

Configuration
=============
* Install the module and navigate to the **Website** portal for project and timesheet access.
* Customers can view their projects, tasks, and timesheets through the portal.
* Use **Settings > Users & Companies** to grant portal access to customers.
* The module extends the Odoo portal with custom login/reset-password templates and task detail views.

Odoo modules dependencies
=========================
* project,
* website,
* aktiv_pms,
* hr_timesheet,
* auth_signup
